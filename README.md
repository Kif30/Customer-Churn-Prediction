# 📊 Customer Churn Prediction (Telecom)

## 🚀 Overview
This project predicts whether a telecom customer will churn using machine learning models based on customer data such as tenure, billing, and services used.

---

## 🧠 Problem Statement
Predict customer churn (binary classification):

- 0 → No Churn  
- 1 → Churn  

---

## 🛠️ Tech Stack

- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib, Seaborn  

---
